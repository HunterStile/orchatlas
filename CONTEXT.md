# OrchAtlas

OrchAtlas coordinates a model team working on one project, while each execution client retains its own authentication and tools.

## Language

**Team**: The assignment of models to orchestration, implementation and review roles.

**Execution client**: The program through which a role uses its model and tools. Codex and OpenCode can participate in the same team.
_Avoid_: Alternative host when describing the combined runtime.

**Run**: One task carried from planning through implementation and review, with its progress retained for inspection or continuation.

**Implementation bundle**: The objective, scope, acceptance criteria and checks assigned to the implementation worker.

**Acceptance**: The reviewer's decision that the observed project changes satisfy the implementation bundle, with evidence.

**Recipe**: A versioned team and workflow selection maintained by the project owner.

**Configuration export**: Generated instructions for manually operating an individual execution client. An export is distinct from an OrchAtlas run.
