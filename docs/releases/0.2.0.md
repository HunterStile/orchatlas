# OrchAtlas v0.2.0 - Interactive orchestration

OrchAtlas now runs a complete model team from one interactive CLI. Type `orchatlas`, choose models with `/model`, and describe a task. Codex plans and independently reviews through your ChatGPT subscription; OpenCode implements and saves files using DeepSeek V4.1 Flash through OpenRouter.

## What changed

- Interactive prompt with slash commands, Tab completion, multiline editing, input history, progress and tool-status events.
- Role-specific model selection from the native client catalogs, including a searchable model picker and reasoning-effort settings.
- Automatic detection of existing Codex/ChatGPT and OpenCode/OpenRouter connections. OpenRouter keys are verified without inference; existing valid logins are reused.
- Saved conversations and runs, bounded follow-up context, cancellation, `/resume`, `/diff` and reports.
- A combined planning, implementation and review loop with correction limits and explicit model/provider checks.
- Windows editable installer with user-PATH registration; wheel and source distribution attached with SHA-256 checksums.

## Install or update

Use Python 3.11+ and install the attached wheel in your Python environment:

```sh
python -m pip install --upgrade ./orchatlas-0.2.0-py3-none-any.whl
orchatlas --project /path/to/your/project
```

Codex CLI and OpenCode CLI must already be installed. The default team requires access to Astra through ChatGPT and an OpenRouter API key connected in OpenCode. The worker ID is `openrouter/deepseek/deepseek-v4.1-flash`. Use `/setup` to inspect connections and `/model` to select models. A direct DeepSeek API key is not required for the default team.

For a source checkout on Windows, run `scripts/install-local.ps1`, then open a new terminal. Full instructions are in the [README](https://github.com/HunterStile/orchatlas/blob/v0.2.0/README.md).

## Compatibility and evidence

The optional v0.1 configuration exports and published recipe snapshots remain available. Existing manifests and saved runs retain their choices. For an older manifest using the direct DeepSeek route, select `/model worker openrouter/deepseek/deepseek-v4.1-flash` for new tasks. Resumed runs keep their original saved team.

86 automated tests cover the terminal, authentication checks, protocols, persistence, permissions, cancellation, corrections and strict review acceptance. A small live task completed Astra planning, actual file writing by DeepSeek through OpenRouter, and independent Astra review, including resuming a saved review. See [validation evidence](https://github.com/HunterStile/orchatlas/blob/v0.2.0/docs/VALIDATION.md) and [CI](https://github.com/HunterStile/orchatlas/actions/workflows/tests.yml).

This remains a prerelease. Live model execution has been validated on Windows; cross-platform CI exercises protocol fixtures and packaging. Images, native-client slash-command passthrough, detached execution and token-by-token model output are not implemented. No model benchmark superiority is claimed. Distribution is through GitHub Releases; no PyPI publication is included.
